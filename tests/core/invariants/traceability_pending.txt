# Safety invariants (HLD §7.5) that have no @pytest.mark.inv test yet.
#
# A ratchet, not a waiver: test_inv_traceability.py fails if an id here IS
# marked, so every WP deletes the lines its tests cover and the list can only
# shrink. It reaches zero when the last safety INV is covered. Nothing may be
# added to it that HLD §7.5 does not list.
#
# Seeded with the whole safety set at WP0.1. The WP that owns each group is the
# one whose PLAN §3 row implements the domain the invariant belongs to.

# INV-1 - precedence; core/allocation only (HLD §3). Covered by WP0.7
# (tests/core/allocation/test_06_comfort_first.py): the ordered walk, comfort
# violators first at any priority, and the one named exception bounded by item 1.

# INV-20–29 - write gate, releases, comfort target, cliffs (HLD §6.4, D4).
# Covered by WP0.5's pure gate decision, kinds and types (tests/core/loads/,
# tests/property/test_gate_matrix.py). WP2.1's executor adds the other half of
# INV-20 (no hass.services call outside writegate.py - already grepped by
# test_single_writer), INV-24 (blocking=True on the call itself) and INV-22's
# scheduled read-back.

# INV-34–42 - budget chain, ladder, trim, rotation, COP (HLD §6.6, D6).
# INV-34–40 are covered by WP0.7 (tests/core/allocation/): ε in kWh, the reserve
# and its two PI gates, the blunt-reason ladder, the proportional trim, the
# smoothed projection against the instantaneous deficit, the two EV stop gates
# and the filtered shed set. INV-39's horizon half - the plan's own stop horizon,
# and the plan half of the budget horizon - was covered by WP0.6
# (tests/core/strategies/test_12_*), the same split as INV-43's in WP0.2.
# INV-41 (rotation) and INV-42 (zones) are covered by D6's group and zone constraints
# (tests/core/allocation/test_12_rotation.py, test_13_zones.py) - the D6 parts of WP3.2 / WP5.3.

# INV-44–48 - publish, isolation, budget, knobs, startup (HLD §6.7, D7)
# → WP0.8 (pure) and WP1.1 (runtime). INV-43's metering half - the window
# closes on the register report, not on the clock - is covered by WP0.2; its
# trigger half (no full tick fires at the boundary) is WP1.1's.
# INV-44 (publish always), INV-45 (per-load isolation) and INV-47 (knobs read live)
# are covered by the pure engine (tests/core/engine/test_engine.py). INV-46 -
# planning I/O never holds the tick lock - and INV-48 - the startup order - are
# covered by the runtime (tests/runtime/test_runtime.py, WP1.1).

# INV-54 - legionella (HLD §6.4, D4 §5.12). Covered by the `water_heater` type
# (tests/core/loads/test_11_*, test_10j, test_14_*). INV-55 (target profiles),
# INV-56 (store maxima), INV-57 (force expiry) and INV-58 (the transport budget)
# are covered by WP0.5; INV-56's other half - `heat_capacitor`'s +Δ respecting

# INV-59 - a cycle is one contiguous block (HLD §6.5, D5). The type half - a running

# (tests/core/strategies/test_07_*); the allocation half by `CycleReservation` (D6).
