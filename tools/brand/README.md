# PowerPlan brand assets

The six PNGs live in `custom_components/powerplan/brand/`. Home Assistant 2026.3+ serves them itself, and local images take priority over the brands CDN (HA developer blog, D8 §5.12, PLAN §7 dec. 29). This directory holds their sources.

| File | Size | Use |
|---|---|---|
| icon.png / icon@2x.png | 256² / 512² | Integration page, device pages, pickers |
| logo.png / logo@2x.png | 484×128 / 967×256 | Light theme wordmark |
| dark_logo.png / dark_logo@2x.png | 484×128 / 967×256 | Dark theme wordmark |

The icon works on both themes, so there is no `dark_icon.png`. `tests/surface/test_brand.py` asserts these sizes.

**Concept:** hourly bars that all stay under a dashed line (the capacity step / fuse limit), with the power bolt also under the line: use power when it's cheap, never go over the cap.

Palette: teal `#12B3A8` → blue `#0A5FA8` tile, amber `#FFC53D` → `#F29D0B` bolt, wordmark ink `#0D2433` + teal `#0B8F87` (dark theme: white + `#5EE0D2`). Font: Inter 700/400, outlined.

| Path | What |
|---|---|
| `icon.svg`, `logo.svg`, `dark_logo.svg` | SVG masters (the generator's own SVG output) |
| `make_brand.py` | the generator: the icon (concept A, plus exploration concepts B and C), the light and dark wordmarks, SVG and PNG |
| `../../docs/images/brand/preview.png` | icon and wordmark on light and dark, shown in the root README (not generated by the script) |

## Regenerate

`cairosvg` and `fonttools` are not project dependencies, and the Inter WOFF files are not vendored. `cairosvg` needs the system cairo library.

```
cd tools/brand
mkdir -p fonts && (cd fonts && npm pack @fontsource/inter && tar xzf fontsource-inter-*.tgz)
~/.local/bin/uv run --no-project --with cairosvg --with fonttools python make_brand.py
cp out/{icon,icon@2x,logo,logo@2x,dark_logo,dark_logo@2x}.png ../../custom_components/powerplan/brand/
cp out/{icon,logo,dark_logo}.svg .
```

The script reads `fonts/package/files/inter-latin-{400,700}-normal.woff` and writes everything to `out/`. Both directories are git-ignored. With `@fontsource/inter` 5.3.0 it reproduces the committed PNGs and SVGs byte for byte (checked).

## Known limitation

HACS store listings still take icons from HACS's own CDN, so the icon may look blank there even though Home Assistant shows it (hacs/integration#5171).
